Containers vs microVMs

Both stacks ran on this Mac on Nov 11, 2026. The difference is the kernel: every Docker sandbox shares one, and every Firecracker microVM brings its own.

Kernel versions are the ones each sandbox reported when we ran it. On phones, scroll the diagram sideways.

Docker sandboxFirecracker microVM
KernelShared with the host VMIts own, per sandbox
IsolationNamespaces and cgroupsHardware virtualization (KVM)
Start timeFelt instant in our runs (not measured)Cold: kernel 1.8 s, SSH 11.8 s (nested on Mac)
Fast Sandbox create, template-backed: 64 ms P50
PackagingOCI images, Dockerfile, registryKernel plus a root disk image (templates)
Runs on a MacYes, through Docker DesktopOnly nested in a Linux VM such as Lima
Best forLocal development and demosMany untrusted agents on Linux servers
The 64 ms figure is OpenSandbox's published Fast Sandbox P50 (serial create). Notes and scripts: github.com/dzuluaga/learn-opensandbox.
